# Frozen Assets

I want to create a bereal equivalent for wild swimming called frozen assets. I want there to be a user login system and use a map api to drop a pin where you found the swim, a photo and a review with some stats. I want it to be as minimal as possible. Im leaning much less  into the social media aspect, i just want people to share swims. I want to use supabase and leaflet apis
